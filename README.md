# KittehCoin ($MEOW) - Your Mom's Favorite Cat Coin

## Project Overview

KittehCoin ($MEOW) is the premiere peer-to-peer internet currency powered by cats. From its 2013 origins alongside Dogecoin to its 2025 revival, KittehCoin represents the ultimate cat cryptocurrency revolution.

## Features

- **Timeline Journey**: Experience the complete story from 2013 origins to 2025 revival
- **Interactive Memes**: Browse through the finest cat memes in a mobile mockup
- **Prophecy Section**: Learn about the cat comeback revolution
- **Modern Design**: Dark theme with premium gold accents and smooth animations
- **Responsive**: Optimized for both desktop and mobile devices

## Technologies Used

This project is built with:

- **Vite** - Fast build tool and development server
- **TypeScript** - Type-safe JavaScript
- **React** - Modern UI library
- **shadcn/ui** - Beautiful component library
- **Tailwind CSS** - Utility-first CSS framework
- **React Router** - Client-side routing
- **Lucide React** - Beautiful icons

## Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <YOUR_GIT_URL>
cd kittehcoin
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:8080`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
